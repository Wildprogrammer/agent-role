# Session Handoff Contract

Use only when no adequate handoff source already exists for an explicit new-conversation handoff, long pause, multi-person handoff, or external resumption. Keep the packet minimally sufficient and link to authoritative information instead of copying it. Never include secret values, raw chat, command noise, or temporary debugging observations. When instantiated, delete unused fields and all instructional prose; do not invent values to fill the template.
