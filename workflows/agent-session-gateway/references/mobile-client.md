# 灵溪 Android 独立终端

手机直接连接电脑网关，无需物理 ESP32 在线。ESP32 设备、小爱 MCP、电脑伴随屏仍是独立通道。

## 首版功能

- 选择 Hermes / DeepSeek Harness 智能体及已有会话，普通问题直接进入该 canonical 会话。
- 文字输入、点击收音，再次点击结束并发送；最长60秒，PCM16 / 单声道 / 16kHz。
- 拍照或选图，预览、移除；照片与文字或语音问题共同提交，绑定变更则拒绝旧照片。
- 默认压缩超过1 MiB的照片：最长边1600像素、JPEG质量0.82，仅在结果更小时使用；原照片不变，可取消勾选发送原图。压缩会损失细节并将透明背景转为白色，需要查看细字或原始细节时可选择原图。
- 上传显示百分比、已发送大小和耗时，100%后仍等待服务器确认。可取消上传；失败、切后台或断线时保留当前页面的照片和问题，不自动重试、不提交智能体。刷新或关闭页面后这些内存内容不保留。
- 完整文字回答与逐段晓伊音频播放；文字进度可先显示，语音在最终答案后分段合成。前4000字可朗读，超过时明确提示，文字不按 ESP32 的200字投影截短。
- 停止立即清空手机播放，电脑端尝试取消该手机正在执行的回合；不承诺未确认的宿主取消成功，不自动重发。
- 回答结束显示12秒追问提示；可再次点击收音。首版不是后台常驻唤醒，也不是免点击实时插话。切后台/锁屏/断网释放麦克风、失效旧结果；返回前台、选图返回或网络恢复时自动检查连接，重连后需手动继续发送。
- 拍照返回保留当前页面内的照片、问题和已显示回答。连接恢复会校验登录、重新读取服务端绑定及智能体/会话列表，不自动改绑、不重放消息或上传。10秒内无法建立连接或收到绑定回执会换连接重试，最多6次、退避最长10秒，失败可点“重新连接”；后台暂停重连，登录过期则提示重新登录。旧连接的迟到消息不能覆盖新连接；系统若销毁整个网页进程，内存草稿仍可能丢失。
- 页面音量只调节手机网页播放增益；系统音量仍由手机调节。
- 顶部“静音 / 仅文字”控制当前手机的语音合成开关：启用后保留完整字幕，不再请求TTS；中途启用立即停止本机播放、取消该手机正在进行的TTS并跳过本轮剩余声音，不取消智能体回答、不影响其他手机或ESP32。重新开启不会补播跳过的内容。偏好保存在当前服务进程的手机身份状态中，刷新重连会读取；服务重启后默认开启语音。旧服务未声明支持时按钮禁用，需加载新版手机后端。
- 首版新建/压缩仍在电脑端完成后选择新会话；完整管理短语会被明确拦截提示，不伪装成普通问题提交。

## 运行结构与依赖

新 `mobile_channel.py` 是 aiohttp HTTP/WebSocket 入口，`mobile_runtime.py` 通过受管启动器可选接入同一 Xiaozhi 进程。它复用同一个 `XiaozhiHermesAdapter`、已加载的支持内存 PCM 输入的 ASR，以及当前 EdgeTTS 音色/语速配置；不新建模型、下载权重或复刻宿主会话。ASR 与 ESP32 共用不可取消推理守卫，忙或超时明确失败。

Python 3.10 服务环境需要 aiohttp（兼容范围 `>=3.13,<4`，验证版本3.13.2）、FunASR/SenseVoiceSmall 与 EdgeTTS；按固定上游依赖准备，不在该环境安装要求Python3.11+的Hub发行包。Hub侧测试使用 `pip install -e ".[dev]"`，独立导入手机模块可安装 `.[mobile]`。证书脚本另需 cryptography（Hub已有依赖）。普通 Hub 安装不会自动启动手机服务；未配置 `-LingxiMobileConfig` 时原服务行为保持不变。

## 局域网 HTTPS

1. 将 `mobile-config.json.example` 复制到仓库外，填写本机当前 IP、专用证书和附件目录。`origins` 必须是精确的 HTTPS origin，无路径。
2. 用脚本生成证书，不修改 Windows 信任库：

```powershell
python <HUB_ROOT>/workflows/agent-session-gateway/scripts/create_mobile_certificate.py --output-dir C:/Lingxi/mobile-tls --host 192.0.2.10 --host localhost --host 127.0.0.1
```

3. 手机只接收并安装 `lingxi-ca.crt` 为受信任 CA。菜单一般位于 Android 安全设置的“安装证书 / CA证书”，厂商路径可能不同；`server.key` 留在电脑。仅点击浏览器“仍然访问”不能保证麦克风可用。证书有效90天，IP变化需重新生成对应证书。
4. 沿用已确认的桥接配置和启动参数，添加 `-LingxiMobileConfig C:/Lingxi/mobile-config.json`。启动前预检精确上游、适配器及配置摘要；如需重启已运行服务，按现有部署门处理。
5. 手机打开 `https://<电脑IP>:8767/`，默认密码 `admin`；可在启动进程环境设置 `LINGXI_MOBILE_PASSWORD`。不自动修改网卡、IP、DNS、防火墙或固件。

## 公网兼容

同一页面使用同源 HTTP/WebSocket，不含固定 PC 地址。独立 HTTPS 反向代理可转发到本入口；外部 HTTPS origin 必须加入 `origins`，保持外部 Host/Origin 并支持 WebSocket。公网入口必须设置专用 `LINGXI_MOBILE_PASSWORD`，不能用默认 `admin`。仅回环监听可省略证书，由代理终止TLS；非回环监听强制TLS。

公网入口按实际部署单独启用；同域共享小爱入口时按精确手机路径转发，保留手机分支的外部Host/Origin。LAN与公网属于不同浏览器 origin，各自生成手机标识、各自登录和显式绑定；选择同一 canonical session 即共享宿主历史，不做账户同步。

## 状态与媒体边界

登录 Cookie 是 HttpOnly，写入要求同源和 CSRF；终端标识只允许 `mobile-<32位随机hex>` 命名空间，不能冒充实体设备ID。浏览器只持久化随机终端标识，不持久化正文、照片、录音和凭据。每个身份一次只允许一个在线页面，刷新需等旧连接关闭。

音频帧携带不可变回合ID；停止、失联和换回合拒绝迟到音频/字幕。每段音频等待浏览器播放完成回执，有明确超时。照片复用现有 AttachmentStore、类型/大小/摘要验证与绑定快照，不接受本机路径。单张最多50 MiB，Hermes图片最多25 MiB；暂存30分钟到期，成功发送后删除。内部桥接只信任 `AGENT_GATEWAY_ATTACHMENT_ROOT`，未设置时兼容小爱的 `XIAOAI_MCP_ATTACHMENT_ROOT`。

结果未知、取消未确认或连接中断后不自动重试。去重为当前服务进程内每手机最近256个请求ID，服务重启不会恢复任务；用户应先去电脑端检查已提交结果。服务器退出不会删除 canonical 历史或绑定。

手机照片上传总时限600秒，每次读取连续60秒没有数据则中止并清理部分文件；浏览器请求时限630秒。小爱附件上传继续使用原有120秒默认总时限。没有分片或断点续传；取消后已成功暂存但未提交的照片由既有过期清理回收。放宽上传时限不能解决ngrok端点离线（ERR_NGROK_3200），也不能保证不稳定网络必然完成上传。

## 验收

软件测试覆盖无ESP32的文字/PCM/照片回合、旧绑定拒绝、重复请求、取消、TTS失败、真实HTTP/WS鉴权和媒体协议。真实 Android 仍需验证：可信HTTPS、麦克风权限、拍照、播放、停止后再次提问、后台恢复，以及 Hermes/DSH 电脑端同会话历史。公共入口需单独实测，不能以局域网结果替代。
